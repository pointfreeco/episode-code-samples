> Another year, another set of UIKit updates, proving that the framework is far from dead! It has adopted more support for the Observation framework, which is nice, but it could go so much further. To see how, we will employ the UIKitNavigation library to show how we can add SwiftUI-like state-driven navigation and controls to a UIKit feature, including animations and even transactions.
