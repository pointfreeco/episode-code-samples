## [Point-Free](https://www.pointfree.co)

> #### This directory contains code from Point-Free Episode: [WWDC26: SQLiteData Observation](https://www.pointfree.co/episodes/ep377-wwdc26-sqlitedata-observation)
>
> This year SwiftData introduced `ResultsObserver`, a brand new way to observe changes outside of the view, where `@Query` for example cannot be used. What’s SQLiteData have to say about that? To explore, we’ll build a moderately complex geofence map editor and get full test coverage of the feature.
